# Results

Everything here is generated by the scripts and never edited by hand:

- `tables/` — `scripts/01_diagnostics.py` (data facts, test windows, dataset statistics) and
  `scripts/07_make_tables.py` (every results table as LaTeX rows `table_*.tex` and as CSV, plus
  `results_facts.tex`, the macro file holding every result number quoted in the paper's text);
- `figures/` — `scripts/08_make_figures.py` (results figures) and `scripts/09_data_figures.py`
  (data and schematic figures), as vector PDF at their printed size.

They are regenerated from the run logs in `runs/` with

```bash
python scripts/01_diagnostics.py && python scripts/09_data_figures.py
python scripts/07_make_tables.py && python scripts/08_make_figures.py
```

See the main README for the mapping from each file to the paper's tables and figures.
